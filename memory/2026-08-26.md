**Bugs found in initial bootstrap script:**
1. Cron IDs I used were **fabricated** (old guesses from MEMORY.md, not actual DB values). All cron rebinds failed silently with "not found" warnings. Fixed by querying the actual cron_jobs DB.
2. `openclaw cron add --payload-file` doesn't exist. The right CLI is `openclaw cron add --agent <id> --session-key <key> --at <time> --delete-after-run ...` (positional message + --tools flag for tool allowlist).
3. `openclaw cron add --session <target>` rejects `agent:main:<workdesk>` format — must use `--session-key` instead.
4. Initial priming crons got 43 tools via `--tools` flag, not the full 47 — missed 4 filesystem helpers. Patched in DB.

**Recipe fixes for `skills/workdesk-bootstrap/SKILL.md`:**
- Cron IDs must be queried from DB, not guessed from MEMORY.md
- Use `--session-key` (not `--session`) for cron add targeting workdesk sessions
- Use `--tools "tool1,tool2,..."` (comma-separated) not `--payload-file`
