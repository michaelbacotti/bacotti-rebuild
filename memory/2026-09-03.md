**Built:**

- `scripts/build_clawrank_features.py` — yfinance pull + per-ticker features
- `scripts/clawrank_backtest.py` — rolling 2y backtest, 85 rebalance periods

**Backtest headline (tech-only v0 — DEFAULT):**
- Spearman IC = −0.011, t-stat −0.31 (NOT significant)
- Q1 vs Q4 spread = −0.32% over 20D, t-stat −0.62 (NOT significant)
- Q1 beat Q4 in 42% of periods (worse than coin flip)
- **Verdict: no statistically significant predictive edge in this universe & window**

**Contrarian variant** (inverted setup lookup, RSI sweet-spot flipped, RS-direction flipped):
- IC = +0.025, Q1>Q4 in 54% of periods (directionally better, still not significant)
- Confirms diagnosis: anti-momentum is closer to truth in 2024-2026 mega-cap regime

**Failure modes diagnosed:**
1. **Look-ahead bias from yfinance .info** — first run got IC=−0.080 (significant negative), which was artifact of using today's fundamentals at every historical date. Fixed by excluding `.info` from backtest entirely.
2. **ETF vs stock asymmetry** — fundamentals exist for stocks, missing for ETFs, creates "stocks vs ETFs" comparison rather than "X vs Y." Fixed by splitting configs.
3. **Momentum factor in mega-cap regime** — NVDA+MSFT+AAPL = ~25% of S&P, all momentum-correlated. Pure momentum has been a documented loser in this regime.
4. **Setup Quality double-counting** — dashboard label rule and ClawRank Setup factor use the same trend+setup logic. Setup factor should be primary, dashboard label derived from it.

### Fix 1: Popover clipping
**Root cause:** `.card { overflow: hidden }` was clipping absolutely-positioned popovers that needed to escape the card boundary.
**Fix:** Changed `.card { overflow: hidden }` to `.card { overflow: visible }`, kept `overflow: hidden` on `.card-header` for rounded corners. Added JS `positionPopover()` that:
- Detects viewport-edge proximity (if popover would overflow right edge, anchor to cell's right edge instead)
- Flips up if it would overflow bottom edge
- Uses `position: fixed` so it escapes any remaining `overflow: hidden` ancestors
- Repositions on scroll/resize
- 120ms hover-leave debounce so cursor can travel from cell to popover without flicker

### Fix 2: Everything was Watchlist
**Root cause:** Label rule required `trend = uptrend AND setup ∈ {breakout, pullback_retest}`. Most tickers are in "range" or "transitioning" trend, so they fell through.
**Fix:** Changed to score-only: Research ≥ 70, Avoid ≤ 30, Watchlist in between. The trend/setup factors are already in the composite (via Technical Momentum + Setup Quality), so the label rule was double-counting.
**Bug fix bundled:** `lib/clawrank.py label_from()` had two bugs:
1. Read thresholds from top-level `cfg` but they live under `composite.label_thresholds`
2. Empty `require_setup_for_research: []` was treated as "never match" instead of "any setup"
Both fixed.
